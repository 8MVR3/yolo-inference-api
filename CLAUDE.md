# yolo-inference-api

Модель YOLO как HTTP-сервис на FastAPI: фото на вход, объекты и количество по классам на выходе.

## Структура

- `app.py` — методы `/health`, `/predict`, `/count`. Модель загружается один раз через `get_detector()`. Фото поворачиваются по EXIF, размер загрузки ограничен.
- `tests/test_api.py` — подменяет модель заглушкой через `dependency_overrides`, поэтому тестам не нужны ни веса, ни видеокарта.
- `Dockerfile`, `docker-compose.yml` — запуск на сервере, веса монтируются из папки `weights`.

## Команды

```
pip install -r requirements.txt
uvicorn app:app --port 8000          # документация на /docs
pytest
docker compose up -d --build
```

Настройки через переменные окружения: `MODEL_PATH`, `IMGSZ`, `MAX_UPLOAD_MB`.

## Правила

- Веса модели не коммитить, они лежат в `weights/` и монтируются в контейнер.
- Каждый новый метод сопровождается тестом с заглушкой.
- Ошибки пользователя возвращаются понятным кодом: 400 на файл, который не изображение, 413 на слишком большой.
